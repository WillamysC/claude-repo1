# Caderninho

Gestão de clientes, vendas e fiado para quem vende e atende pelo WhatsApp: a vendedora de dudu, o técnico de refrigeração, a manicure, o marmiteiro.

O atendimento continua no WhatsApp. O Caderninho guarda quem é cliente, o que comprou, quanto deve e quando precisa voltar, e abre a conversa no WhatsApp com a mensagem pronta (comprovante, cobrança, confirmação de horário, lembrete de manutenção).

- **Protótipo:** [`app/index.html`](app/index.html). Abra no navegador do celular ou do computador; não precisa instalar nada. Vem com dados de exemplo.
- **Ideia, funcionamento do fiado e próximos passos:** [`docs/PRODUTO.md`](docs/PRODUTO.md)
- **Plano e system design do robô no WhatsApp (próximo passo):** [`docs/ARQUITETURA.md`](docs/ARQUITETURA.md)
- **Servidor do robô no WhatsApp (TypeScript, em construção):** [`server/`](server/README.md). Fase 0 pronta; como ligar à Meta está no README da pasta.
